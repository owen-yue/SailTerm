# 运维快捷包（演示插件）

一个**纯命令包**插件（不含 WASM），用一次安装即可试遍插件系统的四类能力。

## 安装

设置 → 插件 → ＋安装本地目录，填入本目录绝对路径：

```
e:\myproject\ai-ssh\SailTerm\examples\plugin-ops-demo
```

安装即把 `manifest.json` + `locales/ko.json` 复制进应用数据目录 `plugins/com.sailterm.opsdemo/`。

## 各能力怎么验证

| 能力 | 位置 | 需要什么 |
|------|------|----------|
| **设置表单** | 插件列表 → 本插件 →「配置」 | 无需会话，装好即可改（字符串 / 数字 / 下拉三种控件）。改动即时落库、按插件 id 隔离。 |
| **命令包** | 配置页下方列出 6 条命令模板 | 声明了 `session_exec` 权限；模板里的 `{{proc_filter}}`、`{{head_lines}}` 会被上面的设置值替换。 |
| **顶栏按钮** 🧭 🖥 | 窗口顶栏，重启后出现 | 需**活动 SSH 会话**才真正执行（`df -h` / `uname -a`，均只读、能过策略）。 |
| **文件右键菜单** | 远程文件面板里右键文件/目录 →「⚡ …」 | 需连上远端文件后端。文件项→尾部 15 行；目录项→占用排行。`{{arg}}` 即右键选中的路径。 |
| **贡献语言** | 设置 → 通用 → 界面语言，多出「한국어」 | 装好并重启/刷新后，选中即整界面切韩语（缺译的键自动回退中文；终端输出不受影响）。 |

## 为什么命令都是只读的

插件命令落地前必经策略引擎（PolicyEngine）裁决，**只放行 ReadOnly**。所以这里用 `df / free / uname / ps|grep|head / tail / du|sort` 这类无副作用命令。
若写 `ping`、`curl` 等网络命令会被判 Write 而被拦下；`rm`、`systemctl restart` 等变更命令同样不会自动执行——这是安全红线，不是插件 bug。

## 已知限制

- 顶栏按钮当前点击后**成功态不弹输出反馈**（结果走独立 exec 通道回到前端但未展示）；想看命令是否真跑，优先用**文件右键菜单**（会在文件面板弹一条执行提示）。
- 没有 `wasm`，故 `on_output` 等钩子、`session_write`/`notify` 的实际动作不生效；本演示只跑命令包模板，已覆盖大多数"快捷命令"场景。
